# オフ会コネクト Webアプリ

Discordログインを使う、少人数のオフ会向け紹介システムです。Sites上のCloudflare WorkersとD1で動作します。

## 実装済み

- Discord OAuth2（`identify`のみ）、有効期限付きセッション。
- 本人によるプロフィール確認・同意・修正・辞退・削除。
- Discord IDによる運営の許可リストと、参加名簿との照合・承認。
- 共通テーマと交流目的からの候補作成、手動紹介、外部AIのJSON取り込み。
- 運営が確認した紹介だけを本人へ公開。
- 本人の希望回答、双方希望の判定、当日の10分枠の割り当て。
- 小グループの手動調整、来場記録、会話実施・振り返り、集計。
- 推薦上限・除外条件・時間重複のチェック。

初版は1イベントを扱います。AI APIによる自動生成やDiscord DM通知はありません。候補の自動下書きは共通テーマに基づくルール方式です。外部AIを使う場合は、募集前に利用するサービスと情報の取り扱いを設定し、運営が出力・取り込みを行います。

## 起動

Node.js 22.13以降が必要です。テストはNode.js 26で確認しています。

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_wooden_mister_sinister.sql
npm run dev
```

ローカルURLは開発サーバーに表示されます。最初のマイグレーションは初回だけ適用してください。`/` は参加者用、`/admin` は運営用、`/privacy` は情報の取り扱いです。

ローカルでは開発用テストログインが表示されます。公開ビルドではテストログインと開発用権限は無効です。テストアカウントは実際のDiscord認証を検証するものではありません。

## 公開環境の設定

次の値はSitesの環境設定に保存します。`.env` ファイルは読み込みません。秘密情報をソース・公開リポジトリに保存しないでください。

| キー | 内容 |
|---|---|
| `APP_ORIGIN` | HTTPSのサイトURL。末尾パスなし |
| `DISCORD_CLIENT_ID` | Discord Developer PortalのApplication ID |
| `DISCORD_CLIENT_SECRET` | OAuth2クライアントシークレット。秘密設定として保存 |
| `ADMIN_DISCORD_IDS` | 運営のDiscordユーザーID。複数の場合はカンマ区切り |

DiscordのOAuth2 Redirectsには `APP_ORIGIN` に `/api/auth/discord-return` を付けたURLを登録します。Botの導入、投稿の読み取り権限、メールアドレス権限は不要です。設定が不足している場合、ログインを開始せず準備中と表示します。

新しいSiteは所有者限定です。参加者へ案内するには、ログイン入口を開く公開範囲の設定が別途必要です。入口を公開しても、アプリ内のデータ閲覧と操作はDiscordセッション・運営ID・紹介の宛先で制御します。

## 保存と同時更新

D1の `app_state` に小規模イベントの状態を保存します。revisionを使った比較更新で同時操作による上書きを防ぎ、競合時は最新状態で条件を再確認します。セッションとOAuth stateは別テーブルで、トークンのSHA-256ハッシュと失効日時を管理します。Discordのアクセストークンは保存しません。

取得時にも保存期限を確認し、開催日から30日後の個人データは返しません。ログイン済みリクエストで削除処理を実施します。無アクセスでも決まった時刻に動く定期ジョブは未設定のため、運営は期限日に管理画面へアクセスし、削除を確認してください。データベースのバックアップ保持条件はホスティング側の条件にも従います。

## 確認

```sh
npx tsc --noEmit
node --test tests/matching.test.ts
node tests/integration.mjs
```

統合テストには起動中のローカル開発サーバーが必要です。作成するのは `local-alice` 等の架空アカウントだけで、テスト後に参加情報を削除します。想定外の参加者データがあれば処理を止めます。公開環境には実行しません。

## 制約

- 対象は1回あたり最大50人の小規模実験です。
- 運営の参加確認、小グループの希望確認、欠席時の再案内は手動です。
- 相互に希望しても、全ての組に紹介枠が確保されるとは限りません。
- 通知はサイト内表示です。Discordへの自動DM送信はしません。
- 開催日・登録締切・AI利用条件等は参加登録後に変更できません。変更が必要な場合は参加者への説明・同意の取り直しを先に行います。
- 期限による削除はアクセス時の処理と運営確認を組み合わせます。
