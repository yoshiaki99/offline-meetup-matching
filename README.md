# オフ会コネクト

Discordコミュニティのオフ会参加者に、本人が提供したプロフィールと今回の交流目的をもとに「話してみると面白そうな人」を紹介するシステムです。

希望者20〜30人程度の実験から始める想定で、Discordログイン、本人の同意、運営による確認、紹介への希望回答、当日の案内と振り返りに対応しています。

## 実装

アプリのソースは `web/` にあります。Sites上のCloudflare Workers・D1を使い、データはログインした本人、運営、紹介先に制限します。

共通テーマによる候補作成はルール方式です。外部AIで作った紹介の取り込みにも対応していますが、AI APIの自動生成やDiscord DMの自動通知は未接続です。

開催情報と募集条件は運営画面から設定します。参加者プロフィール、認証情報、同意記録、AI入出力等の実データはこのリポジトリに保存しません。
